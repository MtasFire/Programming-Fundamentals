# Student sorter program in C

## Purpose
Meant for storing and filtering binary student data which includes name, surname, year and grade
## Features
[x] Dynamic memory address starting at 10 incrementing by 5
[x] Program runtime function which outputs a .log file 
[x] Filtering and alignment functions for all 4 axis
[x] Ability to save data and read data, from and to a binary file
[] Variable error checking for every user input
[] Ability to generate binary data not having to download or write it yourself
## How to run
Execute "studentai.exe" in a terminal
